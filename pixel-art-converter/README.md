# Pixel Art Converter

Модульное клиентское веб-приложение для профессиональной конвертации изображений в пиксель-арт с поддержкой колориметрически точных алгоритмов квантования, ресемплинга, бинарной прозрачности и гибкого управления палитрами.

## Особенности и возможности

### 1. Масштабирование и обработка прозрачности (Alpha & Downsampling)
- **Алгоритмы уменьшения:**
  - **Lanczos-3** — эталонная резкость с широким ядром.
  - **Lanczos-2** — сбалансированная фильтрация.
  - **Bicubic (Catmull-Rom)** — классическая кубическая интерполяция.
  - **Bilinear** — быстрое линейное сглаживание.
  - **Box / Area Averaging** — интегральное усреднение по площади (без артефактов алиасинга).
  - **Nearest Neighbor** — прямое сэмплирование без интерполяции.
- **Гамма-коррекция (Linear Color Space):**
  - При включении интерполяция каналов цвета выполняется в линейном цветовом пространстве (`Linear RGB`) с учетом предварительно умноженного альфа-канала (`Premultiplied Alpha`), что полностью устраняет затемнения и темные ореолы на границах с прозрачностью.
- **Чистая 1-bit бинарная прозрачность:**
  - В итоговом результате исключены полупрозрачные пиксели: пиксель либо 100% непрозрачен, либо полностью прозрачен (`RGBA: 0, 0, 0, 0`).
  - Настраиваемый порог прозрачности (Alpha Threshold, 1–254, по умолчанию 128).
  - **Изоляция ошибок дизеринга:** ошибки диффузии рассеиваются исключительно между непрозрачными пикселями и никогда не загрязняют прозрачный фон.

### 2. Колориметрия и подбор цветов
- **Метрики дистанции цвета:**
  - **CIEDE2000** — математический стандарт перцептивной точности в пространстве `CIE L*a*b*`.
  - **CIE76 / Delta E** — быстрое евклидово расстояние в `L*a*b*`.
  - **Oklab** — современное перцептивно-равномерное цветовое пространство (Björn Ottosson, 2020).
  - **Euclidean RGB** — базовое расстояние.
- **Дизеринг с плавной регулировкой силы (0–100%):**
  - Floyd-Steinberg
  - Atkinson
  - Ordered / Bayer 4×4 и Bayer 8×8
  - Отключен (Nearest Color)

### 3. Управление палитрами
- **Встроенные палитры:**
  - **PixelPlanet Земля** (палитра по умолчанию, 30 цветов).
  - Pico-8 (16 цветов).
  - Game Boy DMG-01 (4 цвета).
  - Endesga 32 (32 цвета).
  - Resurrect 64 (64 цвета).
- **Импорт:**
  - GIMP Palette (`.gpl`)
  - JASC-PAL (`.pal`)
  - Текстовые файлы (`.txt`) со списком `#RRGGBB`, `#RGB`, `rgb(r,g,b)` или значениями через пробел/запятую.
  - Модальное окно для быстрой вставки любого списка цветов из буфера обмена.
- **Инспектор палитры:**
  - Интерактивная сетка образцов (swatches) с отображением HEX.
  - Временное отключение/включение конкретных цветов кликом мыши.
  - Массовые операции: «Все», «Очистить», «Инверт».
- **Экспорт:**
  - Экспорт активной отредактированной палитры в форматы `.gpl` и `.txt`.

### 4. Интерактивный Canvas и UI Material You (M3)
- Сдержанный минимализм Material Design 3 (никакого неона или кислотных цветов).
- Шахматная подложка (Checkerboard) для визуализации прозрачных областей.
- Навигация: плавное панорамирование (Pan) и масштабирование (Zoom) колесиком мыши.
- Пиксельная сетка (Pixel Grid), плавно появляющаяся при масштабе $\ge 400\%$.
- Режим мгновенного сравнения «Оригинал / Пиксель-арт» (сплит-ползунок или удержание кнопки / клавиши `Пробел`).
- Экспорт готового изображения в формате PNG 1:1 в оригинальном пиксельном размере.

## Запуск приложения

Собирать (компилировать) проект **НЕ нужно**. В нём нет Webpack, Vite или Babel — всё работает на чистом современном JavaScript.

### Вариант 1. В один клик (Windows)
Просто запустите двойным кликом файл **`start.bat`** в папке `pixel-art-converter/`. Он автоматически запустит встроенный легковесный сервер и сам откроет браузер.

### Вариант 2. Через встроенный Node.js скрипт
В консоли внутри папки:
```bash
node server.js
```

### Вариант 3. Через любой статический веб-сервер
```bash
# Через Python:
python -m http.server 8000

# Либо через npx:
npx serve .
```
